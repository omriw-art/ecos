# PROJECT DECISIONS

- This is an existing codebase, not a new project.
- Work locally in VS Code.
- Keep changes scoped and commit in small batches.
- Do not migrate to Vite, add a backend, or redesign UI unless explicitly approved.
- Product truthfulness rules apply: no fake users, fake live status, fake activity, fake registrations, or fake social proof.
- Import is replace-only, not merge.
- Unknown imported sectors must not be forced into false canonical sectors.
- ecos-qr.png must not be staged unless explicitly approved.
- Use local/demo/preview wording when functionality is not connected to real backend/cloud/AI.
- Prefer honest empty states over fabricated data.
